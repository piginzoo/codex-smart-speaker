# 02 · 环境与动机：为什么是这台老 Galaxy S9

> 面向未来维护者。读完你应该知道：这台手机的**家底**、它作为"语音终端"的**优劣**、以及环境上那些**绕不过去的坑**（国行无 Google 服务、Android 9 的取与舍、网络分流）。排查细节见 [03-踩坑全记录](03-踩坑全记录.md)。

## 一、这台手机的家底

| 项目 | 参数 | 对本项目的影响 |
|------|------|--------------|
| 机型 | Galaxy S9（SM-G9600，国行双卡版，2018 年发布） | 闲置旧旗舰，废物利用 |
| SoC | 骁龙 845（starqltezc） | 跑 ChatGPT App + 离线语音识别依然够用 |
| 内存 | 4GB（可用约 3.6GB） | 偏紧。ChatGPT App 占 1~1.5GB，Samsung One UI 常驻约 1.5GB，留给管家 App 的余量约 100MB 级——所以管家必须轻量 |
| 屏幕 | 5.8" AMOLED，物理 1440×2960，**系统默认渲染 1080×2220（FHD+）** | ⚠️ adb 坐标按 Override 尺寸算，且**坐标系随横竖屏旋转**——踩过大坑（见踩坑 #6） |
| 系统 | **Android 9（One UI）**，官方最高只能升到 Android 10 | 见下文"为什么停在 Android 9" |
| Google 服务 | **无**（国行固件不带 GMS，无 Play 商店） | 全项目最大的环境障碍，见踩坑 #3~#5 |
| 供电 | 无线充电座常供 | 24 小时监听不心疼电池；但电池常年满电有鼓包风险，属用户自担范围 |
| 音频 | 底部单扬声器 | live 模式默认走"通话音频模式"，需要强制外放路由 |

## 二、为什么选一台老手机，而不是智能音箱 / 树莓派

1. **算力白嫖**：骁龙 845 的 CPU/GPU/NPU 远强于任何智能音箱主控，离线语音识别（Vosk）+ WebRTC 实时语音双开无压力；
2. **喇叭和麦克风是现成的**：自带外放、双麦克风降噪、还有 AMOLED 屏可以显示对话字幕——音箱方案还得自己接外设；
3. **Android 生态现成**：ChatGPT 官方 App 直接装，语音模式开箱即用，不用自己对接 Realtime API（那要自己写音频 pipeline、处理 WebRTC、付 API 费）；
4. **它正好闲着**。

一句话：**不是"为什么用老手机"，而是"老手机恰好是台现成的、会跑安卓的、带喇叭屏幕麦克风的迷你主机"**。

## 三、为什么停在 Android 9，坚决不升级

S9 官方 OTA 最高到 Android 10（One UI 2.5）。看似该升，**实际上不能升**，原因是权限模型的变化：

| Android 版本 | 后台麦克风策略 | 对本项目的影响 |
|-------------|--------------|--------------|
| **9 (Pie)** | 前台服务持有 `RECORD_AUDIO` 即可持续监听，后台录音宽松 | ✅ 息屏听唤醒词的完美土壤 |
| 10 (Q)+ | 引入后台麦克风/摄像头访问限制；11+ 强制前台服务类型声明，"while-in-use" 权限语义收紧 | ❌ 常驻监听唤醒词要么被拒、要么拿到的全是静音 |

本项目的心脏就是"**息屏状态下 24 小时监听唤醒词**"，Android 9 恰好是**最后一代对此宽松的系统**。升到 10 属于"花内存（One UI 2.5 更重）买限制"，纯亏。**结论：停在 Android 9 是特性，不是欠账。**

## 四、国行机的三座大山（环境 obstacles）

### 大山 1：没有 Google 服务（GMS）
国行固件不预装 GMS（Google Services Framework / Play 服务 / Play 商店）。这带来连锁反应：
- 没法从 Play 商店直接装 App → 只能 sideload（侧载）APK；
- **ChatGPT 内置 PairIP 防篡改校验，校验强依赖 Google Play** → 侧载版启动即报 "Something went wrong"，这就是后来**主动装 GMS 三件套**的直接原因；
- 装了 GMS 之后反而不需要手动找 APK 了：Play 商店登录后，"通过 Play 更新"按钮会把侧载版**就地升级成 Play 正渠道版**，并且**自动挑选这台机器能跑的最高兼容版本**（实测装上了 1.2026.314）——比人肉找历史 APK 更稳。

> GMS 作为用户 App 安装（无需 root），按 GSF→Play 服务→Play 商店顺序装，重启生效。全套 APK 已由 apkeep 从 APKPure 拉取，签名指纹均校验过。

### 大山 2：网络可达性
ChatGPT / Google 在直连网络下不可达。本项目的方案是**路由器级分流**：手机 WiFi 裸连，网关侧完成分流转发。手机上零代理软件、零配置——这也是当年拷问时定的铁律（手机上多一个常驻代理进程，在这台 4GB 老机上就是多一个不稳定源）。

### 大山 3：三星系统的小脾气
- **辅助功能服务绑定玄学**：`adb install -r` 会清空 `enabled_accessibility_services` 设置；且 `settings put` 之后服务**不一定立即重新绑定**——实测"重启后的干净状态下 put 直接生效"，其他时机要 reboot。`setup_butler.sh` 就是为此而生（装机后必跑，跑完重启一次）。
- **MtpApplication 弹窗**：Mac 一插线它就弹"请安装三星 S 换机助手"，干扰 UI 自动化——已 `pm uninstall --user 0 com.samsung.android.MtpApplication` 根治（adb 不受影响）。
- **屏幕分辨率双面性**：物理 QHD 但系统默认 FHD+ 渲染，且 `input tap` / 截图的坐标系**随横竖屏旋转**。自动化时必须先 `adb shell wm size` + `dumpsys input` 确认当前方向（详见踩坑 #6）。
